# AKIYA — Digital Creator Website

A static personal-brand website for Akila Induranga.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive visual design
- `script.js` — mobile menu, reveal animations and cursor glow
- `assets/` — supplied AKIYA logo and photos

## Publish
This is a plain HTML/CSS/JS site, so it can be hosted on GitHub Pages, Cloudflare Pages, Netlify, Vercel, or similar static hosting.

## Before publishing
1. Add the real LinkedIn URL.
2. Add the real GitHub URL.
3. Replace the Facebook share URL with the public page URL if available.
4. Add any final project photos/videos.
5. Add a custom domain when ready.
